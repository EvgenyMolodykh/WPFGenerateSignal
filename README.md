# WPFGenerateSignal
WPF-приложение для генерации, обработки, визуализации и хранения цифровых сигналов. Реализованы типовые сигналы (синус, меандр, треугольный, пилообразный), наложение, фильтрация, БПФ, статистика, экспорт/импорт, работа с БД.
