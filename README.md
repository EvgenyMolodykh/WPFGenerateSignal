# WPFGenerateSignal
WPF-приложение для генерации, обработки, визуализации и хранения цифровых сигналов. Реализованы типовые сигналы (синус, меандр, треугольный, пилообразный), наложение, фильтрация, БПФ, статистика, экспорт/импорт, работа с БД.
<hr>
Стек.

<ol>
  <li>.NET 9</li>
  <li>WPF - UI</li>
  <li>SQLite - локальное хранение</li>
  <li>OxyGenPlot - визуализация графиков</li>
  <li>Serilog - логирование</li>
  <li>EF Core - работа с БД</li>
  <li>xUnit + Moq — тестирование</li>
</ol>

<hr>

<h1>Инструкция по установке "Генератор сигналов"</h1>

  <h2>Шаг 1: Скачайте установщик</h2>
    <ul>
        <li>Перейдите на страницу программы</li>
        <li>Нажмите кнопку "Скачать"</li>
        <li>Сохраните файл Setup.exe на свой компьютер</li>
    </ul>

  <h2>Шаг 2: Запустите установку</h2>
    <ul>
        <li>Найдите скачанный файл Setup.exe</li>
        <li>Дважды щелкните по нему для запуска</li>
        <li>Если появится окно безопасности, нажмите "Да" или "Запустить"</li>
    </ul>

  <h2>Шаг 3: Следуйте инструкциям мастера установки</h2>
    <ul>
        <li>Нажмите "Далее" чтобы начать установку</li>
        <li>Прочитайте лицензионное соглашение и примите условия</li>
        <li>Выберите папку для установки (рекомендуем оставить по умолчанию)</li>
        <li>Нажмите "Установить" и дождитесь завершения</li>
        <li>Нажмите "Готово" когда установка завершится</li>
    </ul>

  <h2>Шаг 4: Запустите программу</h2>
    <ul>
        <li>На рабочем столе появится ярлык "Генератор сигналов"</li>
        <li>Или найдите программу в меню Пуск → Генератор сигналов</li>
    </ul>

  <h2>Системные требования</h2>
    <ul>
        <li>Операционная система: Windows 10 или новее</li>
        <li>Место на диске: 100 МБ свободного места</li>
        <li>Установленный .NET Framework 4.8 (устанавливается автоматически при необходимости)</li>
    </ul>
